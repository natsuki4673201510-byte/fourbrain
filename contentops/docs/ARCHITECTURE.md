## 2. 推奨アーキテクチャ

```
┌────────────────────── Mac（ローカル） ──────────────────────┐
│  管理画面 (web/)  ←→  cops.server (127.0.0.1:8765)           │
│                          │                                    │
│                     SQLite (data/contentops.sqlite)           │
│                          │  原稿・PDF (data/products/)        │
│                     ジョブキュー (jobs テーブル)              │
│                          │                                    │
│  launchd(毎日/毎週) → python3 -m cops daily / weekly / run-jobs│
│                          │                                    │
│        エージェント実行エンジン（Phase 2〜）                  │
│        claude -p（Claude Code ヘッドレス, WebSearch/WebFetch）│
└──────────────────────────┼───────────────────────────────────┘
                           │ 承認済みの操作のみ
        X API（公式・従量課金） / 販売プラットフォームAPI / Webhook
```

### 設計の要点
- **依存ゼロ**: Phase 1 は Python 標準ライブラリのみ。`pip install` 不要。
- **エージェント = ジョブ種別**: 市場調査・競合分析・企画・制作・品質検証・SNS・分析の各エージェントは、`jobs.JOB_TYPES` の種別とプロンプト（`prompts/`）の組として実装。個別の有料AIサービスは使わない。
- **実行エンジン**: 既定は **Claude Code CLI のヘッドレス実行（`claude -p --output-format json`）**。Claude 契約の範囲内で動き、追加のAPI費用がかからない。Anthropic API 直叩きは任意の代替（設定 `llm_engine`）で、使う場合は費用を `costs` に記録し上限で止める。
- **重複防止**: テーマ slug / 商品=テーマ1:1 / 原稿 content_hash / 投稿の正規化ハッシュ / ジョブ idempotency_key / 注文ID をすべて DB の UNIQUE 制約で保証。
- **暴走防止**: ジョブのリトライ上限（既定2回・最大5回）、指数バックオフ、1日のジョブ上限、同時制作数上限、商品あたり投稿数上限、月間費用上限（実行中ジョブの見積額も予約として加算）。
- **途中再開**: ジョブは checkpoint を保存。異常終了で `running` のまま残ったジョブは90分後に自動回収。
- **実データとAI推測の区別**: `data_origin`（real / ai_estimate / manual / dummy）。取得できない指標は NULL で、画面には「未取得」と表示（0で埋めない）。
- **ダミーデータの隔離**: デモは別ファイル `demo.sqlite`。画面上部に常時警告バナー。
- **承認ゲート**: 販売開始（外部公開）は `approvals` 経由のみ。SNS は「承認済み」になった投稿だけが配信対象。自動配信は既定 OFF。
- **クラウド移行**: DB はファイル1つ、ジョブは CLI から実行できるので、将来は Claude Code on the web の定期実行や小型VPSに `data/` を移すだけで動く構成。

## 3. 外部サービスの選定と月額費用見積もり

為替 1 USD = 150 円で概算。Claude 本体の契約費は**別枠**（管理画面で記録のみ）。

| 用途 | 推奨 | 月額（初期） | 備考 |
|---|---|---|---|
| AI処理（調査・制作・検証） | Claude Code CLI | **0円**（契約内） | 契約プランの利用上限に依存。上限到達時はジョブが翌日に回る |
| AI処理（代替） | Anthropic API | 0円（既定は不使用） | 使う場合は月間上限内で自動停止 |
| 市場調査データ | Claude Code の WebSearch/WebFetch、公開ページ | 0円 | Google 検索ボリュームの公式な無料APIは無いため、**数値は捏造せず代替指標**（Redditの投稿数・コメント数、マーケットプレイスのレビュー数、検索候補 等）を根拠URL・取得日つきで記録 |
| Reddit | 公開ページの閲覧のみ | 0円 | Data API の商用利用は別契約が必要なため、大量取得はしない |
| PDF生成 | ローカルの Chrome/Chromium ヘッドレス | 0円 | |
| X 投稿 | **初期は手動投稿（管理画面からコピー）** | 0円 | X API は 2026 年現在**従量課金**：投稿 $0.015/件、**URL入り投稿は $0.20/件**、読み取り $0.005/件（公式ドキュメントの記載。最新値は Developer Console で要確認） |
| X 投稿（API自動化後） | X API 従量課金 | 約25〜500円 | 10本/商品×数商品の場合。URL入りにすると1本約30円になるため、**リンクはプロフィール/固定ポストに置く設計を推奨** |
| X 実績取得 | X API 読み取り | 約100〜700円 | 毎日ではなく週次取得にすると費用を抑えられる |
| 販売プラットフォーム | Phase 5 で比較決定 | 0円（固定費） | 手数料は売上連動（例: Gumroad 10%+$0.50、Lemon Squeezy 5%+$0.50、Payhip 無料プラン 5%＋決済手数料。**いずれも未検証の二次情報、Phase 5で公式確認**） |
| 定期実行 | macOS launchd | 0円 | Mac がスリープ中は実行されない（起動時に取りこぼしを実行） |
| バックアップ | ローカルzip + Time Machine / iCloud Drive | 0円 | |
| 独自ドメイン（任意） | — | 約150円 | 年額約2,000円の月割り |

**合計（外部サービス追加分）: 初期 0〜約500円/月、X API 自動化後も約1,500円/月以内** → 目標 2,000円/月に収まる見込み。

### 予算内で注意すべき点（信頼性とのトレードオフ）
1. **Claude 契約の利用上限**: 大量生成すると上限に達しジョブが止まる。対策：1日のジョブ上限・同時制作数上限（設定画面）で平準化。
2. **X API の URL 入り投稿は高額**: 毎投稿にリンクを入れると 1 商品 10 本で約 300 円。上記の通り設計で回避。
3. **検索ボリュームの実数は無料では取れない**: 正確な数値が必要になった場合、有料SEOツール（月数千円〜）が必要で、予算 2,000 円を超える。初期は代替指標で判断し、売上が出たテーマにのみ投資する方針を推奨。
4. **Mac ローカル実行**: 電源・スリープに依存。安定運用が必要になった段階で Claude Code on the web の定期実行等へ移行。
